# Title-and-abstract screening (Section 4.3)

2,716 unique records were screened by four reviewers. An LLM produced a provisional decision and rationale for each record, and a reviewer checked every decision. Screening excluded 2,591 records and produced 125 candidates (see `../4_selection/Candidates_125.csv`).

Files to add to this folder:

- `screening_log.csv`: one row per record, with record ID, title, DOI, the LLM's provisional decision and rationale, the reviewer's final decision, the reason, and the reviewer.
- `llm_screening_setup.md`: the LLM name and version, the access date, the decoding settings (for example, temperature) and the full screening prompt.
