# Quality assessment: study rigour and system maturity (Section 4.4)

Each study is scored on four criteria from 0 to 2 (total 0–8): M1 tool integration, M2 validation design, M3 evaluation scope and M4 deployment indicators. M2 and M3 describe the rigour of the study, and M1 and M4 the maturity of the system it evaluates. Totals map to High (6–8), Moderate (3–5) and Low (0–2). The full rubric is in Supplementary Material S1.

## Agreement for the 29 re-coded studies

- **Quality items:** the two coders gave the same score in 88 of 116 cases (76%). Quadratic-weighted κ was 0.87 for M1, 0.71 for M2, 0.20 for M3 and 0.31 for M4.
- **Extraction fields:** the coders agreed on 163 of 232 values (70%).
- **AI drafts:** where both coders agreed, the AI draft was wrong for 46 of 251 values (18%). Against the final values, it was wrong for 75 of 232 extraction values (32%).

Only the human values are used in the analysis.
